# Film Management System

A simple console-based **Film Management System** built with **Go (Golang)** to practice basic data structures, searching, and sorting algorithms.

## Features

* Add, display, edit, and delete films
* Sequential Search
* Binary Search
* Selection Sort — Title Ascending
* Insertion Sort — Rating Descending

## Data

Each film contains:

* Title
* Genre
* Rating
* Status

The application can store up to 100 films.

## Algorithms

| Algorithm         | Function                  |
| ----------------- | ------------------------- |
| Sequential Search | Search films one by one   |
| Binary Search     | Search sorted film titles |
| Selection Sort    | Sort titles ascending     |
| Insertion Sort    | Sort ratings descending   |

## How to Run

Make sure Go is installed:

```bash
go version
```

Run the program:

```bash
go run UAS.go
```

## Purpose

This project was created to practice **Golang, Struct, Array, Searching, Sorting, and basic Data Structures & Algorithms**.
